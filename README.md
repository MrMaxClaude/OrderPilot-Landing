# OrderPilot Frontend

React/TypeScript website voor OrderPilot landing page en lead magnets.

## Setup
```bash
npm install
npm run dev
```

## Tech Stack
- React 19 + TypeScript
- Vite
- TailwindCSS 4.2
- Motion (animations)
- React Router

## Scripts
- `npm run dev` - Development server
- `npm run build` - Production build
- `npm run preview` - Preview build
- `npm run lint` - TypeScript check
